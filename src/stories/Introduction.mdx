# Design system — Sandra Di Scipio

Token e stili derivati dal file Figma
[SandraDiScipio](https://www.figma.com/design/Zl3k5Q7AegYlr0mGOQa6YQ/SandraDiScipio)
(_Page 1_, tavola _01 · Foundations_), letto il 2026-11-21 tramite il bridge Figma.

| Figma                             | Nel codice                                      | Esempio                                     |
| --------------------------------- | ----------------------------------------------- | ------------------------------------------- |
| `Sandra · Primitives` → `color/*` | `@theme` in `src/styles/tokens.css`             | `bg-ink`, `text-rose-deep`                  |
| `Sandra · Semantic` (Light, Dark) | Variabili CSS + `@theme inline`                 | `bg-background-canvas`, `text-text-primary` |
| `Sandra · Typography`             | `--font-display`, `--font-body`                 | `font-display`                              |
| Stili di testo `Sandra/*` (12)    | Utility `type-*`                                | `type-h1`, `type-eyebrow`                   |
| `space/*`                         | Scala Tailwind con passo di 4 px                | `p-4` = space/16                            |
| `radius/*`, `layout/*`            | `rounded-*`, `max-w-site`, `mobile:`, `tablet:` | `rounded-pill`                              |
| `Sandra · Motion`                 | `--duration-*`, `ease-editorial`                | `duration-(--duration-fast)`                |

La modalità **scura** si attiva con `data-theme="dark"` su un elemento antenato. In Storybook si cambia dal selettore _Mode_ nella barra degli strumenti.

Quando cambia un valore in Figma, aggiorna `src/styles/tokens.css` (decisione D-055 in `docs/04-decisioni.md`).
