# Glossario

| Termine | Significato in questo progetto |
| --- | --- |
| V.0 | Prima versione del sito da pubblicare. Ambito definito in [02-requisiti-business.md](02-requisiti-business.md) |
| POC | Il sito Astro già presente nel repository (`src/`). Prototipo esplorativo, **non** base vincolante (D-001) |
| PO | Product Owner: Sandra Di Scipio, che valida contenuti e scelte |
| Chiavi in mano | Servizio completo: dal progetto alla realizzazione dei lavori, con eventuale fornitura degli arredi |
| Solo progetto | Servizio solo digitale: render, piante, scelta di arredi e materiali. I lavori li fa realizzare il cliente per conto suo |
| Preventivatore | Sezione con i due questionari (Chiavi in mano, Solo progetto). Nella V.0 non calcola prezzi (D-004) |
| Progetti non conclusi | Progetti universitari o accademici, mai realizzati |
| Progetti conclusi | Progetti professionali. Ogni scheda ha la parte digitale e la parte interior (D-003) |
| Parte digitale | Render, piante, concept, tavole di un progetto |
| Parte interior | Foto reali del lavoro realizzato |
| Render | Immagine fotorealistica generata al computer di un ambiente progettato |
| Pianta | Disegno in vista dall'alto di un ambiente (distribuzione, arredi) |
| Prima/dopo | Confronto tra stato di partenza e risultato finale |
